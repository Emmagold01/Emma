# **Emmanuel's Portfolio**

A modern, responsive **developer portfolio** built with **Next.js**, **Tailwind CSS**, and **TypeScript**.  
Showcasing projects, skills, and creative UI design.

---

## **✨ Features**

- **Next.js 14** with App Router
- **Tailwind CSS** for utility-first styling
- **Responsive Design** for all screen sizes
- **Custom Fonts** (Poppins, Roboto, Fira)
- **Reusable Components:** Navbar, Footer
- **Dynamic Routing** for multiple pages
- **Clean Folder Structure**

---

```bash
git clone https://github.com/your-username/your-repo-name.git

3. Run the development server
```
